📖 How to Add an App

  1. Upload your APK/EXE to Google Drive
  2. Right-click → Share → Anyone with the link
  3. Copy the file ID from the URL
  4. Fill the form above → click Generate Code
  5. Open data.js in your repo
  6. Paste the code inside the APPS array
  7. Commit & push → Netlify auto-deploys in 30 seconds ✅
